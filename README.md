# PulseFit — Gym Landing (Astro + GitHub Pages)

Landing page for gym management app, built with Astro.

## Dev
```bash
npm install
npm run dev
```

## Deploy
Push to `main` — GitHub Action builds and deploys to GitHub Pages.

In repo Settings → Pages, set Source to **GitHub Actions**.

Site will be at `https://Samir-Lama.github.io/gym-test/`
